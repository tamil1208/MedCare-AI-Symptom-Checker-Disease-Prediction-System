🚀 What is MedCare?

Machine Learning platform that analyzes symptoms, age, gender, blood pressure, and cholesterol to predict diseases with 95%+ accuracy. Provides instant treatment recommendations and risk assessment using trained Random Forest models.

Built for rapid diagnosis in remote areas, clinics, and personal health monitoring. Processes 1000s of predictions per minute with Flask API backend.

Flask backend handles 1000+ requests/minute
